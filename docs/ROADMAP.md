## Delivery workflow

Issue → feature branch → implementation → tests → commit → push → pull request → review → merge to `main` → automatic deployment.

## Public-data rule

Only public technical status belongs in this hub. Credentials, personal identifiers, contracts, private customer data and tokens must never be committed.
